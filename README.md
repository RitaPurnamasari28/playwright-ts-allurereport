# Playwright End-to-End Test Automation

Automated end-to-end web testing suite built with Playwright and TypeScript.

## Project Overview

The core test automation framework in this repository was designed and built from scratch, covering project structure design, UI element locator mapping, and end-to-end test scenario development. To streamline test reporting, this project also integrates Allure Report along with an automated Gemini AI failure analysis summary developed with AI assistance.
